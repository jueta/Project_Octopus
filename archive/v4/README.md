# Project Octopus v4 Archive

This directory preserves the last battery-era baseline of Project Octopus.

It exists as a reference point for:

- the original PIR-triggered, low-power concept,
- the firmware that already captures and sends photos through Telegram,
- the hardware references that supported assembly and flashing,
- the lessons learned about battery life and power budgeting.

Contents:

- [`Firmware/`](Firmware/): preserved PlatformIO project and camera logic
- [`Hardware/`](Hardware/): preserved hardware reference images
- [`../../docs/v4/`](../../docs/v4/): photos and renders from the latest v4 prototype state

This archive should stay stable unless we intentionally need to fix or document something inside the preserved baseline.
